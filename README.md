# Task2Project 06.16.24

Spring Boot REST API project created as a university assignment.

## Tech stack
- Java 21
- Spring Boot 3.2.5
- Spring Data JPA
- H2 Database
- Maven
- Swagger (OpenAPI)

## Project description
The project implements a simple REST API for managing products.
It follows a layered architecture:
- Controller
- Service
- Repository
- DTO

## Available endpoints
All endpoints are documented using Swagger UI.
